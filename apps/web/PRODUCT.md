# Just Imagine web

A parent-owned learning and play app for children aged 6–13. The child uses voice, taps, drags, choices and numeric controls; never free text. Parents manage profiles, review worlds and discoveries, and control captions, session targets and billing.

The approved visual direction is warm, playful cartoon character presentation and a calm parent area, optimized for a landscape tablet. The Tooth Town acting standard now extends to 39 other Learn characters, six preset friends/guides and eight pets through local registered raster poses; Tooth Town retains its existing eight poses. Learn keeps its habitat paintings, native interactive diagrams and nine stories. Actual playback amplitude drives discrete speech poses; optional external Rive rigs retain their existing Studio mounting path. These assets establish sprite acting, not film, a continuous skeletal rig or phoneme lip-sync. Custom photo portraits, single-image outfits and old generated worlds do not gain authored pose coverage; arbitrary generated animation-art reliability remains open.

`NEXT_PUBLIC_FAKE=1` is a clearly labelled local preview with persistent browser sample profiles, playable fixture worlds, disabled microphone capture and unavailable billing. Real mode uses Firebase Auth/Firestore, a server-verified session cookie, the REST API, and the voice gateway. No live credentials or hosting are configured by this app.
