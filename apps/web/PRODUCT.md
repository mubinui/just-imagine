# Just Imagine web

A parent-owned learning and play app for children aged 6–13. The child uses voice, taps, drags, choices and numeric controls; never free text. Parents manage profiles, review worlds and discoveries, and control captions, session targets and billing.

The approved visual direction is warm, playful cartoon character presentation and a calm parent area, optimized for a landscape tablet. The product currently has code-native character and world placeholders; final Rive and illustrated assets are external prerequisites. Do not present them as finished assets.

`NEXT_PUBLIC_FAKE=1` is a clearly labelled local preview with persistent browser sample profiles, playable fixture worlds, disabled microphone capture and unavailable billing. Real mode uses Firebase Auth/Firestore, a server-verified session cookie, the REST API, and the voice gateway. No live credentials or hosting are configured by this app.
