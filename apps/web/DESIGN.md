# Built design

Warm cream ground (#fff9ee), deep green foreground (#243e36), forest actions (#245e4e), muted leaf, ochre and clay accents. Locally hosted Baloo provides soft rounded headings; Nunito provides readable body copy. The landing composition pairs a large question with an abstract geometric play window. It makes no claim that geometric placeholders are final illustration.

The Studio places the interactive canvas first, with a quieter companion panel, readable captions over the world, prediction choices and lab controls below. Child controls have a minimum 64px target. Parent controls use 44px targets, quiet dividers, conventional forms and a persistent navigation rail; the rail becomes horizontally scrollable on narrow screens. Dialogs trap keyboard focus, dismiss with Escape and restore focus.

The child and parent worlds share typography and semantic colors. Motion duration is a token and becomes zero with reduced-motion preferences. Physics remains interactive. Parent forms and all actionable child controls retain visible keyboard focus. Browser selection, progress meters and range inputs use the same palette.

Reviewed production captures at 1280px and 390px. Fixed mobile grid overflow and ambiguous dial labels. Placeholder character presentation and engine fallback geometry are intentionally visible. Final painterly assets, Rive animation, real-device audio and child usability remain release gates.
