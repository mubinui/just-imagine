# Plan A3: Web App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `apps/web`, the Next.js application that carries the marketing landing page, parent sign-up and sign-in, the child app (Who's playing?, Studio, Gallery), and the parent area (dashboard, children, plan and billing, settings), wired to the engine (Plan A1), the voice client and characters (Plan A2), Firestore world delivery, and the REST contract, and deployable to Firebase App Hosting.

**Architecture:** A Next.js 16 App Router app with three route groups: `(marketing)` and `(auth)` are public, `(child)` is a client-rendered play surface that runs under the parent's Firebase session and talks to the gateway over WebSocket and to Firestore through a `WorldSource`, and `(parent)` is gated by a server component that verifies the Firebase session cookie. All UI is built with the `impeccable` skill under two committed visual worlds (the child Studio world and the calm parent world) that share one token file. `NEXT_PUBLIC_FAKE=1` swaps the gateway URL, the world source, and the REST transport for the fakes from `packages/fixtures` so the whole app runs and is end-to-end tested without Vertex AI, the builder, or the api service.

**Tech Stack:** Next.js 16.4 (App Router, Turbopack, React 19.3) on Firebase App Hosting; TypeScript 5.9 strict; Tailwind CSS 4 with CSS design tokens; Firebase JS SDK 12 (Auth, Firestore) in the browser and `@just-imagine/server-core` (Firebase Admin) in route handlers and server components; Zod 4; Vitest 3 with jsdom and Testing Library; Playwright 1.56 with `@axe-core/playwright`; `@just-imagine/engine`, `@just-imagine/characters`, `@just-imagine/protocol`, `@just-imagine/scene-schema`, `@just-imagine/fixtures`.

**Spec:** `docs/superpowers/specs/2026-10-15-just-imagine-design.md` (sections 2, 3, 4.2, 6.4, 6.5, 6.5a, 7.3, 8.10, 10, 11, 12, 13, 14, 15). Global constraints and the cross-plan review focus: `docs/superpowers/plans/2026-10-15-just-imagine-master.md`. The contract this plan consumes: `docs/superpowers/plans/2026-10-15-plan-0-foundation.md` Tasks 8, 9, 10, 11, 12, 13, 17, 18.

## Global Constraints

See the master plan; every task here includes them. Additional constraints for this plan, with values copied from the spec and the verified vendor docs:

- Next.js `^16.4.0` (16.x is the Active LTS line, released 2025-10-21; 16.4 shipped 2026-10-06 with React 19.3; Turbopack is the default bundler; `next build` no longer runs ESLint). Firebase App Hosting supports Next.js 13.5 and higher on Node 22 or higher, detects pnpm from `pnpm-lock.yaml`, and supports Turborepo monorepos when the backend's root directory is set to `apps/web`. Cache Components stay off this round: the parent pages render per request behind a session cookie and the Studio is a client surface.
- Package name `@just-imagine/web`, ESM, TypeScript `strict` with `noUncheckedIndexedAccess`. Workspace packages export TypeScript source, so `next.config.ts` lists every `@just-imagine/*` dependency in `transpilePackages`; `firebase-admin` is in `serverExternalPackages` and every module that imports `@just-imagine/server-core` imports `server-only` first.
- Every UI task invokes the `impeccable` skill (`Skill: impeccable`) before the first edit and again for the finish. The child surfaces (Who's playing?, Studio, Gallery) and the parent area are two directions; both are realistic-cartoon, Disney-inspired, cute, and legible on a tablet in landscape; the parent area is also calm and trustworthy (restrained color strategy, standard controls). The landing page is a Persuade surface, the child surfaces are Experience surfaces, the parent area is an Operate surface.
- The child never enters free text: no `<input type="text">`, `<textarea>`, or `contenteditable` renders under `app/(child)`. Child input is tap, drag, flick, dial, slider, and numeric keypad only.
- Tap targets on child surfaces are at least 64 by 64 CSS pixels (`--tap-min: 64px`); parent surfaces at least 44 by 44. Every interactive element is reachable by keyboard in the parent area; the child area supports keyboard too but is designed for touch.
- Captions of character speech default on for bands `8-10` and `11-13`, off for `6-7`; the per-child `captions` field written by the parent overrides the default.
- Audio: iOS Safari starts with the AudioContext suspended; the tap on a profile in Who's playing? is the one user gesture that unlocks audio (`unlockAudio()`), and it happens before `connect()`. No second gesture is ever required.
- World content never travels over the WebSocket; the Studio reads world documents through `WorldSource.subscribe(worldId, ...)` and parses them with `WorldDocSchema`.
- Reconnect: on an unexpected socket close the Studio reconnects with exponential backoff (500 ms, 1 s, 2 s, 4 s, 8 s; five attempts) sending the same `sessionId` and `worldId` in `hello`; the world subscription is keyed on `worldId` only and survives reconnects.
- `NEXT_PUBLIC_FAKE=1`: gateway URL defaults to `ws://127.0.0.1:8787` (the `startFakeGateway` CLI), the world source is `FakeWorldSource` over `progressiveScript` for all fixture worlds, the REST transport is an in-browser fake that implements `ROUTES`, and audio capture is disabled so Playwright needs no microphone. Firebase Auth still runs (against the emulator in tests).
- All user-facing strings live in `apps/web/lib/strings/en.ts`; components never contain literal copy.
- Reduced motion: every animation reads its duration from the motion tokens, and `@media (prefers-reduced-motion: reduce)` zeroes them; JavaScript-driven motion checks `useReducedMotion()`. State changes stay visible without motion.
- Plan limits, bands, characters, dials, and concept copy are never redefined in this app; they come from `@just-imagine/protocol` and `@just-imagine/scene-schema` (`PLAN_LIMITS`, `QUOTA_WARNING_SECONDS`, `AgeBandSchema`, `CHARACTERS`, `guidesFor`, `DEFAULT_CHARACTER`, `GRAVITY_PRESETS`, `WIND_PRESETS`, `conceptCard`).
- Commit messages are Conventional Commits (`feat(web): ...`), end with prose, and never carry a Claude or Anthropic attribution line.

## Review Focus

Inputs the spec implies that no happy-path test covers. Each line names the task that carries the test.

1. **The WebSocket drops while a world is building.** Expected: the Studio shows "reconnecting", keeps the same `worldId` and `sessionId`, reconnects with them in `hello`, and the world still renders when the `WorldSource` emits `ready`; the world subscription is created exactly once. Pinned in Task 7 (`use-studio-session.test.tsx`, "keeps worldId across a socket drop and still renders the world").
2. **Captions default follows the band and the parent toggle overrides it.** Expected: `effectiveCaptions({ ageBand: '6-7', captions: true })` is `true`, `effectiveCaptions({ ageBand: '8-10', captions: false })` is `false`, and `defaultCaptionsFor` is `false` only for `6-7`; the captions line renders only when effective captions are on. Pinned in Task 10 (`captions.test.ts`, `captions-line.test.tsx`).
3. **Labs keypad entry outside `[min, max]`.** Expected: the value is clamped to the bound and snapped to `step`, the engine receives the clamped value, and exactly one `variable` message is sent. Pinned in Task 11 (`slider-panel.test.tsx`, "clamps a keypad value and sends exactly one variable message").
4. **A guide the band cannot summon.** Expected: for a `6-7` child the cast strip renders no button for `onkomama`; for `8-10` it renders all six; for `11-13` it renders the three guides only, because companions are not configured for that band. Pinned in Task 9 (`cast-strip.test.tsx`).
5. **The profile tap is the only gesture.** Expected: tapping a profile calls `unlockAudio()` exactly once and never `connect()`; the Studio calls `connect()` only when audio is already unlocked and never calls `unlockAudio()` again. Pinned in Task 6 (`profile-picker.test.tsx`) and Task 7 (`use-studio-session.test.tsx`, "never connects before audio is unlocked").

`apps/web/lib/env.ts`:

```ts
import { z } from 'zod';

const FirebaseSchema = z.object({
  apiKey: z.string().min(1),
  authDomain: z.string().min(1),
  projectId: z.string().min(1),
  appId: z.string().min(1),
});

export interface Env {
  fake: boolean;
  useEmulators: boolean;
  gatewayUrl: string;
  apiUrl: string;
  clipsBaseUrl: string;
  firebase: z.infer<typeof FirebaseSchema>;
}

const wsUrl = z.string().regex(/^wss?:\/\//, 'NEXT_PUBLIC_GATEWAY_URL must start with ws:// or wss://');

export function readEnv(source: Record<string, string | undefined>): Env {
  const fake = source['NEXT_PUBLIC_FAKE'] === '1';
  const useEmulators = source['NEXT_PUBLIC_FIREBASE_EMULATOR'] === '1';
  const firebase = FirebaseSchema.parse({
    apiKey: source['NEXT_PUBLIC_FIREBASE_API_KEY'],
    authDomain: source['NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN'],
    projectId: source['NEXT_PUBLIC_FIREBASE_PROJECT_ID'],
    appId: source['NEXT_PUBLIC_FIREBASE_APP_ID'],
  });
  if (fake) {
    return {
      fake,
      useEmulators,
      gatewayUrl: wsUrl.parse(source['NEXT_PUBLIC_GATEWAY_URL'] ?? 'ws://127.0.0.1:8787'),
      apiUrl: source['NEXT_PUBLIC_API_URL'] ?? 'http://127.0.0.1:8788',
      clipsBaseUrl: source['NEXT_PUBLIC_CLIPS_BASE_URL'] ?? '/clips',
      firebase,
    };
  }
  const required = (key: string): string => {
    const v = source[key];
    if (!v) throw new Error(`${key} is required when NEXT_PUBLIC_FAKE is not set`);
    return v;
  };
  return {
```

```ts
function channel(c: number): number {
  const s = c / 255;
  return s <= 0.03928 ? s / 12.92 : Math.pow((s + 0.055) / 1.055, 2.4);
}

export function relativeLuminance(hex: string): number {
  const m = /^#?([0-9a-f]{6})$/i.exec(hex.trim());
  if (!m) throw new Error(`expected a 6-digit hex color, got "${hex}"`);
  const n = parseInt(m[1]!, 16);
  return 0.2126 * channel((n >> 16) & 255) + 0.7152 * channel((n >> 8) & 255) + 0.0722 * channel(n & 255);
}

export function contrastRatio(a: string, b: string): number {
  const la = relativeLuminance(a);
  const lb = relativeLuminance(b);
  const [hi, lo] = la > lb ? [la, lb] : [lb, la];
  return (hi + 0.05) / (lo + 0.05);
}
```

```ts
'use client';
import { useSyncExternalStore } from 'react';

const QUERY = '(prefers-reduced-motion: reduce)';

function subscribe(cb: () => void): () => void {
  if (typeof window === 'undefined') return () => {};
  const mq = window.matchMedia(QUERY);
  mq.addEventListener('change', cb);
  return () => mq.removeEventListener('change', cb);
}

export function useReducedMotion(): boolean {
  return useSyncExternalStore(
    subscribe,
    () => (typeof window === 'undefined' ? false : window.matchMedia(QUERY).matches),
    () => false,
  );
}
```

```tsx
  variant: Variant;
  size: Size;
  busy?: boolean;
  children: ReactNode;
}

export function Button({ variant, size, busy = false, disabled, className = '', children, type = 'button', ...rest }: ButtonProps) {
  return (
    <button
      type={type}
      aria-busy={busy || undefined}
      disabled={disabled || busy}
      className={`inline-flex items-center justify-center gap-2 font-semibold transition-[transform,filter,background-color] duration-quick ease-out-expo disabled:opacity-60 disabled:cursor-not-allowed ${VARIANT[variant]} ${SIZE[size]} ${className}`}
      {...rest}
    >
      {children}
    </button>
  );
}
```
