# A1 engine report

Implemented `@just-imagine/engine` in packages/engine. Public source exports `createSimulation`, `mountEngine`, `Simulation`, `Engine`, `SimulationSnapshot`, `EngineEvent`, `Pose`, and `Spell`.

Both engines expose load/update, fixed-step stepping, tap/drag/flick, setDial, setVariable, castSpell (optional target tag), reset/dispose, snapshot, and subscribe. Browser Engine adds canvas. `step(n)` advances n ticks. Spell vocabulary accepts protocol reverseGravity/slowTime/grow/shrink/floatAll/restore (legacy aliases slowMotion/float also work). Event names include rule, say, tap, drag, flick, dial, variable, spell, launch, celebrate, sound, challengeComplete. Rule/say events carry ruleId and concept; say text is in say. Challenge ID is target. Interaction summaries throttle at 500ms, variables at 300ms per variable; bounded input history records each input.

Rapier2D headless core implements bounds, shapes, materials, joints, seeded spawns capped at 24 entities, medium buoyancy/drag, space zero gravity, numeric bindings, all closed-vocabulary rule/action kinds, once rules, collisions with force impulse threshold, challenges, plots/histograms sampled at 10Hz, stopwatch state, and bounded histories. Soft dynamic entities use nine spring-connected nodes and sprites with assets use a 3x3 Pixi MeshPlane driven by those nodes. SceneDoc is cloned; asset updates preserve runtime poses; changed bodies rebuild independently (joint edits rebuild world). Spells restore the pre-spell runtime settings.

Pixi v8 renderer uses WebGPU preference with Pixi fallback, DPR <=2, responsive 16:9, backdrop/mid/entity/overlay order, interpolated render positions, all eight visual variants, pointer interaction, body highlights/behaviors, cancellation generations for late texture loads, ResizeObserver/ticker/pointer cleanup. Headless import is safe.

Verification: seven real Rapier tests pass (determinism/immutability, progressive update/reset/dispose, variable clamp/snap and bounded history, once rule metadata/spawn, physical collision challenge, soft lattice/unaffected-body edits, protocol spell restore). Typecheck and ESLint pass. Browser esbuild minified ESM bundle is 2.2MB raw and 820,517 bytes gzip including Rapier/Pixi, under the 1.2MB gzip budget. No new tests mock Rapier. Rapier compat emits its own deprecated-init-parameters warning even through its documented zero-argument init.

Remaining practical limitations: no GPU/browser automation or real iPad frame-rate measurement was available in this package pass. Drag uses a damped velocity spring approximation rather than a dedicated pointer joint; flick velocity is estimated by the browser adapter. Material softness changes rebuild the affected body, but runtime material switching does not reconstruct an existing lattice. Soft lattice nodes receive medium forces via their central body rather than individual displaced volumes; large scaling changes do not retune all lattice spring rest lengths. Particle emission is a lightweight decorative burst and not a persistent particle solver. Mid-layer is layered but camera parallax has no effect with the fixed camera. Histogram represents currently tagged-body positions, not cumulative landing trials. These should be considered during browser acceptance testing.

## Fix round 1 — review findings addressed

Addressed all ten findings in engine-review.md plus inverse-rotated pin anchors and failed Pixi initialization cleanup. Source imports remain extensionless for Next compatibility. No shared schema/protocol contracts changed. Additive engine APIs: `frame()` returns current poses/visual state/gravity without history or replay input metadata, `cancelDrag(id)` releases a hold without a flick, and `setCollider(id, unknown)` safely accepts optional normalized convex collider assets.

Document joints are now reconciled after body, material, collider, scale and joint changes without resetting clock, once-rules, challenges or unrelated poses. Rebuilds preserve current pose/velocity and retain each trial's landing identity. Rule removals persist through asset updates. Added/changed variables initialize bindings and removed variables leave snapshots. Runtime effective materials drive buoyancy and every lattice node receives medium forces; floatAll explicitly supplies upward acceleration regardless of density. Polygon scaling reconstructs the polygon, and restore touches only scales actually overridden.

Soft bodies now have nine equal small-circle colliders with rotated initial offsets, no full rigid collider, and runtime material changes create/remove lattices. Scaling rebuilds spring rest lengths. Drag uses an actual spring to a persistent kinematic pointer anchor; pointer release measures a bounded last-80ms movement window, while cancellation releases without launching. Taps briefly highlight the target. Histogram semantics are accumulated settled landing trials: a tagged body must contact a fixed support and have speed below 0.15m/s; each body contributes once until another launch/flick. The latest 500 observations survive body removal, and challenges inspect these accumulated trials.

Entity removal clears scale/launch/material/medium/hold/collider state. Visual removal clears corresponding caches. TextureLease owns decoded ImageBitmap/Texture resources outside the global Assets cache and releases/aborts them on replacement/dispose, including late decodes. Every placeholder and background layer slot is created synchronously, then all asset requests run independently with generation guards. Auto-shape colliderUrl responses are bounded to 64KB and validate finite normalized coordinates in [-0.5,0.5], at most 40 contour/part vertices and 12 convex parts; invalid/failed assets preserve placeholder physics. Soft lattices retain their node physics while storing accepted contours for later rigid material changes.

Rendering uses `frame()` rather than cloning histories. Overlay Text/Graphics and a bounded particle pool are retained across frames. Vector overlays use effective runtime gravity. Browser init failures destroy partially initialized applications; normal cleanup also cancels pending collider fetches and owned textures.

Verification: 25 package tests pass, including new real Rapier joint/body update, rotated pin anchor, tombstone/variable update, effective density, dense-body float/restore, polygon restore, persistent spring drag, accumulated landing challenge, rotated/material-switched lattice, validated collider updates, bounded spawn/remove caches, and non-recounted trial regressions. Renderer/gesture/texture tests cover immediate placeholders while background loads remain unresolved, overlay object retention, pointer cancellation, nonzero flick velocity with unchanged pointerup coordinates, failed GPU init, texture release and late-decode disposal. Typecheck and ESLint pass.

Real Chromium smoke using installed Playwright and the bundled source with software WebGL passed: jelly fixture mounted, physics advanced with four entities/nine soft nodes, 960x540 canvas, dispose/remount/dispose left zero canvases, no page errors. Whole initial mount + 300ms advancement + remount finished in about 452ms. This is browser lifecycle evidence, not an iPad performance measurement. Updated minified browser ESM gzip size: 810,378 bytes including Rapier and Pixi.

Remaining acceptance scope: actual iPad frame-rate profiling and visual taste/interaction review remain device QA. Fixed-camera mid-layer parallax has no visible displacement. The probability model intentionally records settled support contacts, rather than encoding a separate DSL landing-zone field. Prior report limitations about rigid center colliders, drag approximation, density spells, collider assets, texture ownership and present-position histograms are superseded by this fix round.

## Fix round 2 — scoped review closed

Resolved the four remaining important findings and texture retry recovery. On document body/material rebuilds, unchanged active entity bindings are reapplied with the currently selected runtime values; selected variables take precedence over document material defaults, while explicitly changed variable definitions initialize their new value. Collider outlines are invalidated when sprite/collider source identity changes and fallback geometry is rebuilt while retaining live pose; same-source updates retain accepted outlines. Asset changes without a prior outline preserve soft-node poses and existing runtime physics. Replacement convex water colliders retain sensor semantics.

Collider metadata now streams through readBoundedJson: one fixed 64,000-byte buffer, Content-Length early rejection, byte accounting before copying each chunk, and immediate AbortController/reader cancellation on overflow. No response.text() buffering occurs. Failed TextureLease promises are evicted with partial-resource cleanup, allowing later same-URL updates to retry.

Added real Rapier playthroughs of the new unmodified LAB_WORLDS fixtures. Galton Board releases and settles sufficient balls to complete collect_six from accumulated histogram trials while respecting the 24-entity cap. Fractions Lab splits a whole into two pieces, drags them into physical collision to complete share_together, recombines, and splits the newly spawned whole again. No fixture defects were found.

Final verification: 33 tests across six files pass; package typecheck and ESLint pass. Focused regressions cover selected density/scale after body+material document changes, collider-source replacement/fallback versus same-source retention, auto-water pass-through before/after collider arrival, streamed oversize/Content-Length rejection, and same-URL texture retry. Stable APIs and extensionless imports are preserved; no shared contract or dependency changes were required. This round does not introduce additional device-performance claims beyond the previously recorded Chromium lifecycle evidence.
