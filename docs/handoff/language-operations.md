# English and Bangladeshi Bangla operations — 2026-10-17

Active implementation: [language-consistency-plan.md](language-consistency-plan.md). The parent’s language setting governs shared screens, child screens, Live speakers, new generation and translated editions of saved books/worlds. Only `en` and `bn` are accepted; Bangla uses `bn-BD` on the page and natural Bangladesh vocabulary. The existing demo release/tag is retained.

## Settings and source map

Parent → Settings → App and conversation language saves the active child’s choice before updating the browser. Parent → Children retains per-profile language editing. Before a child exists, the same control records the browser’s preference. Profile selection notifies mounted navigation in the same tab. The shared root updates typography, strings and document language/title; leaving child routes no longer resets the app to English. The active child remains authoritative on the Live server. An ended call releases its owned lease after final metering, before the slow model summary, so a new-language call does not wait for summary generation. Late completion of the old call cannot remove a replacement call’s lease; both gateway and Firestore regression tests cover the handoff.

- `apps/web/lib/i18n/{index,ui,ui-bn,bn}.ts`: selection, subscriptions, original typed table and additional explicit authored UI copy. No DOM text replacement. Unknown user-chosen names, emails and technical IDs remain data; known preset names have deliberate script forms. Numbers and dates follow the selected locale.
- `components/LanguageRoot.tsx`, `LanguagePreferencesForm.tsx`, `ProfilePicker.tsx`, `ParentPanels.tsx`: application scope and successful-save synchronization. The child companion closes an old-language session without disposing the newly unlocked audio context.
- `packages/protocol/src/language-policy.ts`: common exclusive output instruction for companions, authored learning characters, imagined characters, Katha, scenes and generated game prose. A child asking in another language does not override the parent setting. Native-audio Live uses system instructions rather than an unsupported explicit `speechConfig.languageCode`; see [Google Live capabilities](https://ai.google.dev/gemini-api/docs/live-api/capabilities).
- `packages/learning-content/src/`: Bangladesh wording/name corrections preserve IDs, facts, assets and play rules. Bengali subsets are self-hosted; Baloo/Nunito component declarations resolve their Bengali glyphs to the approved Bengali faces.

## Saved editions

The user explicitly requested translated saved content. `X-App-Language: en|bn` on authenticated parent API reads selects a display edition; no header retains the canonical response for compatibility. The API always verifies ownership before model work. `packages/protocol/src/content-language.ts` enumerates display-prose paths. `packages/server-core/src/content-editions.ts` stores a source-prose fingerprint and translated text under the source’s private `languageEditions/{en|bn}` subcollection. Source edits invalidate the cache; progress-only changes reuse it with the latest progress. Same-process identical work is deduplicated. The canonical record is never overwritten.

World scripts/hashes, physics, IDs, tags, numeric controls, answer indices, illustrations and bookmarks are outside the translation allowlist. Story prose, questions, choices and learning passages translate while retaining action/choice IDs. Gateway narration reads the same cached story edition that the browser displayed. An unavailable edition produces a recoverable error rather than a successful response containing the wrong language.

`services/api/src/editions.ts` calls the existing server-side Gemini fast model/key, with schema/count/script/length/placeholder validation and one correction attempt. Long books are split into batches of at most 16 entries or 3,000 source characters, with at most 3 model calls concurrently; HTTP attempts are bounded. Whole-book responses timed out during the first real check, so that implementation was replaced. Initial translation takes model time; reopening uses a cache. No new image generation is required.

Generated game runtime prose uses `POST /v1/worlds/:worldId/text-edition` (owned world, strict en/bn, up to 16 strings of 1,000 characters). `lib/content-voice-copy.ts` translates HUD labels/questions/options/captions without rewriting game code. Number placeholders share translations across changing scores; per-world runtime caches retain the latest 256 phrases. A separate private per-family translation counter bounds work to 160 uncached translation operations per UTC day. It does not spend new-world/image allowance. This is a cost guard, not a paid-plan change.

Every cache read and final write rechecks parent consent, child/source ownership and family/child/item deletion fences. Late model results cannot recreate deleted content. Individual story deletion now recursively removes edition subcollections after its tombstone is written. Existing recursive world/child/family cleanup covers their editions.
