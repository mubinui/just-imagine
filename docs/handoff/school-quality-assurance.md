## Publication and AI boundaries

`lessonPublicationChecks` is shared by the teacher interface and publication API. Publication requires an explanation before the graded quiz, bilingual usable text and hints, distinct choices/questions, stated experiment instructions/goals, keys and private example solutions for simulation/lab tasks. Placeholder and clearly wrong-language content block approval. Repeated generic hints, uniform MCQ positions, missing practice and assessment variety are recommendations. Incomplete drafts can still be saved. An author can inspect a localized Publication checks summary before publishing.

The API verifies every supplied task witness with the actual locked-parameter solver or deterministic lab grader. Publishing also refuses a simulation task already solved at its starting settings. The witness stays in server-only answer keys. Save, approval and publication bind their validated snapshot to the caller’s expected revision before entering the transaction, with the transaction checking it again. A crafted future revision cannot reuse validation or old private keys against a concurrent newer edit. Existing model/chapter pairing, parameter validation, numeric computed readings, bilingual approval, class ownership and audited operator publication remain active.

AI Generate/Refine and translation remain proposals. Refinement/translation reject clearly wrong-language output and changed numeric facts/common SI quantities, accepting Bangla numerals and common translated unit names. These checks do not prove prose semantics or every possible notation; teachers must review scientific meaning, curriculum fit, worked examples, answer keys and bilingual equivalence. The whole-lesson prompt now requests those teaching elements and executable private task witnesses. No live provider request was made during this quality pass. Existing saved text remains unchanged on rejection.

## Concrete corrections

- Parallel SVG wires now require current to cross a resistor. Tests reconstruct connectivity for one, two and three branches and independently check current/power identities.
- Cart motion uses a fixed metre scale and a following camera, rather than dividing every trajectory by its own final displacement. Force/mass experiments therefore show different motion. Graphs show numeric scales.
- Invalid simulation input shows an explicit problem, disables running and suppresses diagrams/readings/tutor observations instead of silently substituting defaults. SVG pointer coordinates use inverse screen transforms, including phone letterboxing and parameter locks.
- Chemistry discards delayed success/error responses after edits, reset or unmount. Known deterministic observations return without an AI call or fabricated equation. Model-supplied pH is refused. Quantitative pH is limited to the ideal 25°C dilute HCl/NaOH/KOH domain, 0.001–0.1 M; other quantitative mixtures have unknown pH/indicator colour. Curated no-amount reference conditions remain separate.
- Numeric grading shares a strict decimal/Bangla/Unicode-minus parser with the client and uses exact canonical-decimal tolerance comparison. Inclusive boundaries pass; hexadecimal/binary input does not. The teacher percentage control now correctly converts displayed percentages to relative fractions.
- Each quiz section submits its own required questions; completion still covers all quiz sections. Progressive hints stay under their own question. Changed answers/steps invalidate late grading/hint feedback.
- On first submission to a changed lesson revision, the old attempt is archived at `schools/{school}/attempts/{student}_{lesson}/revisions/{revision}`. Current correctness/tries/completion reset; lifetime credit prevents repeated points for reused question IDs. Historical answers/first-correct data remain archived. Read projections never display old-revision correctness as current mastery.
